# Security Policy

## Reporting a Vulnerability

Please report security vulnerabilities privately via GitHub's
[Security Advisories](https://github.com/ychaparala/getflashlight/security/advisories/new)
— **do not open a public issue**. You should get a response within a few days.

## Supported Versions

Only the latest released version on [PyPI](https://pypi.org/project/getflashlight/)
is supported. Please upgrade before reporting an issue that may already be fixed.
